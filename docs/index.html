Online Retail: Customers, Retention & Revenue

1,067,371 transaction lines from a UK online gift retailer, Dec 2009 – Dec 2011, cleaned and analysed with SQL (DuckDB) and Python. Wholesale-heavy customer base, so order values are high.

Built by Nabeel Khan · Code & SQL on GitHub · Data: UCI Online Retail II (CC BY 4.0)

Cohort retention

% of customers from each first-purchase month who bought again N months later

Only about 1 in 5 customers comes back in any given month. Retention rises again at month 12 for the autumn 2010 cohorts, because Christmas buyers come back for the next Christmas. The Dec 2009 cohort looks unusually loyal because it includes customers who were already buying before the data starts.
